= UpLift and Shift の紹介

*Red Hat OpenShift on AWS で OpenShift Virtualization を活用し、レガシー VM を改善する*

== 前提条件

このワークショップに必要なのは、最新の Web ブラウザだけです。
Firefox、Chromium、Safari で動作確認を行っています。

== はじめに

UpLift and Shift ラボへようこそ。このラボでは、OpenShift Virtualization を活用して従来の仮想マシン (VM) をモダンなクラウドネイティブプラットフォームへ移行する方法を体験します。
このハンズオンでは、既存の仮想化環境から Red Hat OpenShift Service on AWS を基盤としたスケーラブルかつセキュアな環境へ VM を移行する手順を学びます。安定性と信頼性を損なうことなく移行を実現できます。

従来の仮想化プラットフォームからの移行を検討する多くの企業は、スピード、コスト効率、モダナイゼーションのバランスという課題に直面しています。
パブリッククラウドへのワークロード移行を経験済みの方は、オンプレミスのワークロードをクラウド環境に移す従来型の Lift and Shift アプローチをご存じでしょう。
この方法は初期移行を簡素化しますが、多くの場合、次の 2 つの選択肢しか残りません。

アプリケーションモダナイゼーション::
レガシーアプリケーションをモダンなサービス指向アーキテクチャに合わせて再設計、書き換え、リプラットフォームするアプローチです。
変革的ではありますが、*多大な時間とリソースを要します。*

Lift and Shift::
最小限の変更で VM をクラウドへ迅速に移行するアプローチです。
ただし、モダンな機能の恩恵を受けられず、コスト増につながることが多いです。

*UpLift and Shift* 戦略は、これらに代わる魅力的な選択肢を提供します。

VM を Red Hat OpenShift Service on AWS に移行することで、スケーラビリティ、セルフサービスプロビジョニング、CI/CD パイプライン統合といったモダンなプラットフォーム機能を、VM 自体を変更することなく活用できます。
このアプローチは、Lift and Shift のスピードとシンプルさに高度な機能の付加価値を加え、レガシーアプリケーションをそれぞれのペースで進化させられます。

== AWS 上の OpenShift Virtualization のメリット

*Red Hat OpenShift Virtualization* は、Red Hat OpenShift Service on AWS の一部として提供されるフルマネージドプラットフォームです。データセンターのハードウェア管理の負担なく、VM をモダンなインフラストラクチャに移行できます。
このハイブリッドクラウドソリューションにより、オンプレミス、クラウド、エッジ環境にわたって、一貫したプロセスとツールで VM を管理できます。

主なメリット：

* *移行と管理の簡素化*: レガシープラットフォームからモダンなマネージドインフラストラクチャへ、VM をシームレスに移行
* *価値創出までの時間を短縮*: VM のデプロイと CI/CD パイプラインとの統合で効率を向上
* *ハイブリッドクラウドの柔軟性*: 多様な環境にわたって VM とコンテナワークロードを一貫して運用
* *自分のペースでイノベーション*: モダナイズの準備ができた段階で、コンテナベースのワークロードやサーバーレスアプリケーションなど、OpenShift のクラウドネイティブ機能を活用
* *マネージドサービス*: 日常的なプラットフォーム管理を Red Hat と AWS のエキスパートに任せ、IT チームは戦略的な取り組みに集中

Lift and Shift の手軽さとモダンなクラウドネイティブ機能を組み合わせることで、*OpenShift Virtualization on AWS* は組織のモダナイゼーションを加速します。クラウドとオンプレミス環境にわたって、VM とコンテナアプリケーションを統一的に運用できます。

このラボでは、OpenShift Virtualization を活用して VM を「UpLift（アップリフト）」し、ハイブリッドクラウドインフラストラクチャの可能性を引き出す手順を体験します。チームがより速くイノベーションを起こし、より大きな価値を届けられるようになります。
