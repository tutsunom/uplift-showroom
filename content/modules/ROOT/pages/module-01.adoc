= ダッシュボード: Operator、マルチテナンシー、リソース使用率

== はじめに

Red Hat OpenShift Service on AWS (ROSA) は、堅牢で拡張性に優れたマルチテナント対応のアプリケーションプラットフォームです。

ROSA は OpenShift であり、Operator の豊富なエコシステムを備えています。
Operator により、OpenShift 上に追加の製品を簡単にインストール・管理できます。
Red Hat は Operator Catalog を通じて数十のフルサポート製品を提供しています。
さらに、Red Hat 認定済みの Partner Catalog を含めると、利用可能な Operator は数百に上ります。

OpenShift のマルチテナンシーは管理が容易で、Kubernetes コミュニティとの 10 年以上の協業に基づいています。
Project（Namespace）がこの機能の中核です。

このワークショップはマルチテナンシーの優れた実例です。
あなたと他の参加者は、同じ ROSA クラスター上に専用の OpenShift ユーザーと Project を持っています。
あなたの OpenShift ユーザーには、仮想マシンとアプリケーション専用の 2 つの Namespace へのフルアクセス権があります。
また、一部の Namespace に対しては限定的なアクセス権が付与されています。
これらの Project は Web コンソールに表示されます。
情報収集やネットワーク間の通信に利用されます。

OpenShift のダッシュボードは、クラスター全体（特にクラスター上で動作する仮想マシン）のあらゆる情報を集約する堅牢で設定可能なツールです。
ここで、それらのダッシュボードを確認してみましょう。

== システムへのアクセス

ワークショップ環境は共有の ROSA クラスター上にあります。
他の参加者も同じクラスターを使用しているため、OpenShift の内部動作へのアクセスは制限されています。
あなたのユーザーでは見えない OpenShift の重要な機能については、このワークショップガイドで説明とスクリーンショットを提供します。
このきめ細かなアクセス制御こそ、OpenShift の強力なマルチテナンシーの表れです。
1 つの OpenShift クラスター上で多数の Project を互いに干渉することなく実行できます。

このワークショップはすべて OpenShift Console を通じて行います。

== リソース使用率

一見簡単に思えますが、すべての VM から使用率メトリクスを収集することは、特にクラウド環境では容易ではありません。
OpenShift は、クラスター上で実行するすべての VM に対してダッシュボードを自動生成するため、これを手軽に実現できます。
リソースメトリクスは時系列データベースに保存され、様々な時点での使用率を確認できます。また、独自のダッシュボードで表示したい場合はエクスポートも可能です。

. windowsmesh-{user} Project の仮想マシン一覧を表示します。
左側のバーで *Virtualization -> VirtualMachines をクリック* します。
次に、上部のバーで *Project: `windowsmesh-{user}` を選択* します。
+
image::module-1-virtual-machines.png[Virtualization VirtualMachines]
+
. *winweb01* VM をクリックして、VM の Overview を表示します。
+
image::module-1-virtual-machine-list.png[Virtual Machines List,link=self, window=blank, width=100%]
+
*「Metrics」タブをクリック* して、この VM のリソース使用率情報を確認します。
+
image::module-1-virtual-machine-metrics.png[Virtual Machine Metrics,link=self, window=blank, width=100%]
