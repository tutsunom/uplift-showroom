= 宣言的 IaC による VM リソースの自動化

== はじめに

OpenShift と Kubernetes の利点の一つは、構成が宣言的な YAML マニフェストで管理されることです。
OpenShift 上で動作する VM の構成も同様です。
他のシステムでは、新しい仮想マシンインスタンスの作成や既存の仮想マシンの構成管理を自動化するために、複雑な IaC 言語の理解が必要になることがあります。

このモジュールでは、あらゆる IaC システムで容易に採用できる手法を使って、VM に割り当てる CPU リソースを増やします。

[[validating]]
== 初期 CPU コア数の確認

.  変更対象の VM を見つけるには、左側のバーで *Virtualization -> VirtualMachines をクリック* します。
上部のバーで *Project `windowsmesh-{user}`* を選択します。
+
.`winweb01` 仮想マシンの特定
image::module-2-find-winweb01-vm.png[Find winweb01 VM,width=50%,link=self, window=blank]
+
.  *`winweb01` VM をクリック* します。
*Overview* タブの CPU | Memory セクションを確認します。
+
.VM の CPU およびメモリ消費量
image::module-2-winweb01-cpu-ram.png[winweb01 CPU and RAM,link=self, window=blank, width=100%]
+
. `winweb01` コンソールの PowerShell でコア数を確認します。
.. *Console タブ* をクリックし、*黒いコンソールボックス* をクリックして VM コンソールへの入力を有効にします。
.. *`15` を入力* して PowerShell を起動します。
+
.Microsoft `SConfig` へのアクセス
image::module-5-powershell-01.png[SConfig,link=self, window=blank, width=100%]
+
.. 以下のコマンドをクリップボードに *コピー* します。
+
[,powershell,subs="attributes",role=execute]
----
Get-CimInstance -ClassName win32_processor | Select NumberofCores
----
+
参考として、Windows 仮想マシンの物理メモリは以下のコマンドで確認できます。
+
[,powershell]
----
(Get-CimInstance Win32_PhysicalMemory | Measure-Object -Property capacity -Sum).sum /1gb
----
+
. *Paste ボタン* を使って VM コンソールに貼り付けます。
+
.IaC 再構成前のコア数を確認するためのコンソールアクセス
image::module-2-winweb01-numcores-1.png[winweb01 numcores 1,link=self, window=blank, width=100%]

[[increasing]]
== CPU コア数の増加

. IaC を使って CPU コア数を増やすには、*YAML タブをクリック* し、`cpu` が見つかるまでスクロールします。
約 190 行目で、`cores` の値を *1 から 2 に変更* します。
. *Save* をクリックします。
+
.YAML 編集によるコア数の変更
image::module-2-winweb01-cpu-2-cores.png[winweb01 CPU 2 cores,link=self, window=blank, width=100%]
+
. winweb01 VM を再起動するには、*円形の矢印* &circlearrowright; をクリックします。
. `winweb01` VM の再起動を待ちます。
. `winweb01` コンソールの PowerShell でコア数を確認します。
.. *Console* タブをクリックし、黒いコンソールボックスをクリックして VM コンソールへの入力を有効にします。
.. 先ほどと同様に、メニューで *15* を入力して PowerShell を起動します。
.. 新しいコア数を確認するには、以下のコマンドを *コピー/ペースト* して Paste ボタンで VM コンソールに貼り付けます。
+
[,powershell,subs="attributes",role=execute]
----
Get-CimInstance -ClassName win32_processor | Select NumberofCores
----
+
.CPU 数の実際の変更を確認
image::module-2-winweb01-numcores-2.png[winweb01 numcores 2,link=self, window=blank, width=100%]

NOTE: Infrastructure as Code を使って必要な再起動をトリガーすることもできます。仮想マシンを再構成した後、`virtctl` を実行する Job で仮想マシンを再起動するパイプラインを実装することも可能です。
