= GUI による仮想マシン管理

== はじめに

このモジュールでは、OpenShift Virtualization における VM の作成と管理の基本を体験します。テンプレートから仮想マシンを GUI で作成し、プロパティの確認や基本的なカスタマイズ、ライブマイグレーションなどの管理操作を行います。

.*目標*

* 新規プロジェクトの作成
* テンプレートからの仮想マシン作成
* 仮想マシンのリソースの確認
* VM の電源状態の管理
* VM のライブマイグレーション

[[create_project]]
== 新規プロジェクトの作成

OpenShift では、Project（Kubernetes の Namespace）がリソースやアクセス権を管理する単位になります。VMware の vSphere における「リソースプール」や「フォルダ」に近い概念です。

. 左のナビゲーションメニューから *Virtualization* -> *VirtualMachines* をブラウズします。
+
image::module-02-gui/01_Left_Menu.png[link=self, window=blank, width=100%]
+
[NOTE]
====
*Virtualization* タブは、OpenShift Virtualization Operator がインストール・設定済みの場合に表示されます。このラボ環境ではすでに設定済みです。
====

. ウィンドウの左上にある *Project* ドロップダウンをクリックし、*Create Project* をクリックします。
+
image::module-02-gui/02_All_Projects.png[link=self, window=blank, width=100%]

. *Name* フィールドに *vmexamples-{user}* と入力し、*Create* をクリックします。
+
image::module-02-gui/03_Create_Project.png[link=self, window=blank, width=100%]

[[create_vm]]
== Linux 仮想マシンの作成

. *Create VirtualMachine* ボタンをクリックし、ドロップダウンメニューから *From template* を選択します。
+
NOTE: VM は InstanceType ウィザードや YAML 定義からも作成できますが、今回はテンプレートを使用します。後のモジュールで YAML による作成も体験します。
+
image::module-02-gui/04_Create_VM_Button.png[link=self, window=blank, width=100%]

. 利用可能なテンプレートの一覧が表示されます。
+
"Source available" の青いバッジが付いたテンプレートは、ソースディスクがすでにダウンロード・保存済みであることを示しています。
+
image::module-02-gui/05_Create_VM_Templates.png[link=self, window=blank, width=100%]

. *Fedora VM* タイルを選択します。
+
image::module-02-gui/06_Create_VM_Quick.png[link=self, window=blank, width=100%]

. 名前を *fedora01* に変更し、*Quick create VirtualMachine* をクリックします。
+
image::module-02-gui/07_Create_VM_Quick_Name.png[link=self, window=blank, width=100%]

. 数秒後、VM が *Running* 状態になります。テンプレートのディスクがクローンされ、新しい VM 用のブートディスクが作成されています。
+
image::module-02-gui/08_Fedora_Running.png[link=self, window=blank, width=100%]

. *Events* タブで作成プロセスの詳細を確認します。問題が発生した場合もここに表示されます。
+
image::module-02-gui/09_Fedora_Events.png[link=self, window=blank, width=100%]
+
* まず _DataVolume_ が作成されます。DataVolume は VM ディスクの作成（クローンやインポート）を管理するリソースです。
* その後、VM が起動します。

. *Overview* タブをクリックして、VM の詳細を確認します。デフォルトでは CPU が 1、メモリが 2GiB に設定されています。
+
VM の IP アドレス、ストレージ、システム使用率、ホストノードなどの情報もこのページに表示されます。
+
image::module-02-gui/10_Fedora_Details.png[link=self, window=blank, width=100%]

[[admin_vms]]
== 仮想マシンの構成確認

. *Configuration* タブをクリックして、仮想マシンのリソース情報を確認します。
+
image::module-02-gui/11_Configuration_Tab_Nav.png[link=self,window=blank,width=100%]
+
以下のサブタブがあります。VMware vSphere の「設定の編集」に相当する各種設定がここに集約されています。
+
image::module-02-gui/12_Configuration_Tab.png[link=self, window=blank, width=100%]
+
* *Details* : CPU やメモリの変更、ホスト名の変更、ブート順の変更など、基本的なハードウェア設定を編集できます。
* *Storage* : 接続されたディスクの一覧と、新しいディスクの追加が可能です。
* *Network* : ネットワークインターフェースの設定を確認できます。
* *Scheduling* : VM の配置先ノードに関する設定（アフィニティルール、ノードセレクタなど）を行います。
* *SSH* : SSH アクセスの設定や公開鍵の注入が可能です。
* *Initial run* : Linux の場合は _cloud-init_、Windows の場合は _sysprep_ を設定できます。
* *Metadata* : VM に適用されたラベルとアノテーションを確認・編集できます。

. *Storage* サブタブをクリックして、VM に関連付けられたディスクを確認します。
+
image::module-02-gui/13_Storage_Tab.png[link=self,window=blank,width=100%]

. *Network* サブタブをクリックして、ネットワークインターフェースを確認します。
+
image::module-02-gui/14_Network_Tab.png[link=self,window=blank,width=100%]
+
VM はデフォルトで *Pod Networking* 上に *masquerade* タイプのインターフェースで接続されます。これにより、VM は OpenShift の SDN に接続され、クラスター内外との通信が可能になります。

[[vm_state]]
== 仮想マシンの状態の制御

Web コンソールから仮想マシンの停止、起動、再起動、一時停止、一時停止解除ができます。VMware vSphere の電源操作に相当する機能です。

. *Overview* タブに戻ります。

. 右上に Stop、Restart、Pause のショートカットボタンと、*Actions* ドロップダウンメニューがあります。
+
image::module-02-gui/15_VM_State_Actions.png[link=self, window=blank, width=100%]
+
* *Stop* : グレースフルシャットダウンを実行します。
* *Restart* : OS に再起動信号を送信します。
* *Pause* : VM のプロセスをフリーズします。メモリは割り当てられたままです。

. *Actions* メニューをクリックして、利用可能なオプションを確認します。
+
image::module-02-gui/16_VM_Actions_Menu.png[link=self, window=blank, width=100%]

. *Stop* ボタンを押し、VM が *Stopped* 状態になるのを待ちます。
+
image::module-02-gui/17_VM_Stopped.png[link=self, window=blank, width=100%]

. *Actions* をクリックすると、*Start* が表示され、*Restart* と *Pause* はグレーアウトされています。
+
image::module-02-gui/18_VM_Actions_List_Stopped.png[link=self, window=blank, width=100%]

. *Start* をクリックし、*Running* ステータスになるのを待ちます。

. *Actions* メニューまたはショートカットボタンから *Pause* を実行します。VM の状態が *Paused* に変わります。
+
image::module-02-gui/19_VM_Actions_Paused.png[link=self, window=blank, width=100%]

. *Unpause* で一時停止を解除します。

[[live_migrate]]
== 仮想マシンのライブマイグレーション

VMware vMotion と同様に、OpenShift Virtualization でも VM を停止せずに別のノードに移行できます。

. *Overview* タブに移動します。
+
[NOTE]
====
ワークショップのユーザーはクラスター管理者ではないため、VM の稼働ノード名は表示されません。下記のスクリーンショットは管理者で表示した例です。ただし、マイグレーション自体は実行可能です。
====
+
image::module-02-gui/20_VM_Info_Node.png[link=self, window=blank, width=100%]

. *Actions* メニューから *Migrate* を選択します。
+
image::module-02-gui/21_VM_Dialog_Migrate.png[link=self, window=blank, width=100%]

. VM のステータスが *Migrating* に変わり、数秒後に *Running* に戻ります。ライブマイグレーションが完了しました。
+
image::module-02-gui/22_Migrated.png[link=self, window=blank, width=100%]

[[cleanup]]
== 仮想マシンの削除

後のモジュールで使用するリソースを確保するため、作成した VM を削除します。

. *Actions* メニューから *Delete* を選択します。
. 確認ダイアログで *Delete* をクリックします。

WARNING: `fedora01` を削除しないと、後のモジュールでリソースが不足する可能性があります。
