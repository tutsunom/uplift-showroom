= 宣言的 IaC による仮想マシンの作成自動化

== はじめに

次に、YAML タブを使って新しい仮想マシンの作成を自動化します。
これを行うために必要な 2 つのものを用意しています。

. 目的の OS、基本構成、および必要に応じてデプロイ済みアプリケーションを含む仮想マシンイメージ。
. OpenShift に仮想マシンのデプロイ方法を指示する YAML マニフェスト。

WARNING: このラボの完了後は、必ず新しい仮想マシン `winweb03` を *削除* してください。削除しないと、ワークショップの残りの演習に必要なリソースが不足します。

[[yaml]]
== YAML マニフェストを使った仮想マシンの作成

. 上部のバーの *Projects:* ドロップダウンで *windowsmesh-{user}* Project を選択し、正しい Namespace にいることを確認します。
. 右上の *VirtualMachines -> Create -> With YAML* をクリックします。
+
.新しい仮想マシンのページを探す
image::module-3-create-with-yaml-dropdown.png[Access virtual machine YAML,link=self, window=blank, width=100%]
+
. *あらかじめ作成されている YAML を削除* します。
*以下の YAML テンプレートをコピー/ペースト* します。
*Create* をクリックすると、新しい仮想マシンが作成されます。
+
.新しい仮想マシンのマニフェスト（作成準備完了）
image::module-3-paste-yaml-and-create.png[Paste YAML and Create,link=self, window=blank, width=100%]
+
[source,yaml,subs="+attributes",role=execute]
----
apiVersion: kubevirt.io/v1
kind: VirtualMachine
metadata:
  labels:
    app: winweb03
    app.kubernetes.io/part-of: 3-Tier-App
    vm.kubevirt.io/template.revision: '1'
    vm.kubevirt.io/template.version: v0.25.0
  name: winweb03
  namespace: "windowsmesh-{user}"
spec:
  dataVolumeTemplates:
  - apiVersion: cdi.kubevirt.io/v1beta1
    kind: DataVolume
    metadata:
      name: winweb03
    spec:
      source: # <1>
        snapshot:
          name: winweb03-volumesnapshot
          namespace: default
        # http:
        #   url: 'http://s3.us-east.cloud-object-storage.appdomain.cloud/roadshowocpvirt/winweb01.qcow2'
      storage:
        resources:
          requests:
            storage: 90Gi
  running: true
  template:
    metadata:
      labels:
        app: winnetworking
    spec:
      domain:
        clock:
          timer:
            hpet:
              present: false
            hyperv: {}
            pit:
              tickPolicy: delay
            rtc:
              tickPolicy: catchup
          utc: {}
        cpu:
          cores: 1
          sockets: 2
          threads: 1
        devices:
          disks:
          - disk:
              bus: sata
            name: rootdisk
          inputs:
          - bus: usb
            name: tablet
            type: tablet
          interfaces:
          - masquerade: {}
            model: e1000e
            name: default
        features:
          acpi: {}
          apic: {}
          hyperv:
            frequencies: {}
            ipi: {}
            relaxed: {}
            reset: {}
            runtime: {}
            spinlocks:
              spinlocks: 8191
            synic: {}
            synictimer:
              direct: {}
            tlbflush: {}
            vapic: {}
            vpindex: {}
          smm:
            enabled: true
        firmware:
          bootloader:
            efi: {}
        machine:
          type: q35
        resources:
          requests:
            memory: 6Gi
      networks:
      - name: default
        pod: {}
      terminationGracePeriodSeconds: 3600
      volumes:
      - dataVolume:
          name: winweb03
        name: rootdisk
----
<1> 仮想マシンイメージは、インポート済み VM イメージの PVC スナップショットをクローンして提供されます。これが最もパフォーマンスの高い方法です。
+
[.left]
. 新しい `winweb03` 仮想マシンが 3 つのフェーズを経て起動する様子を確認します。
+
.. `WaitingForVolumeBinding` - この VM 用の新しいストレージボリュームが作成されます。
+
image::module-3-waitingforvolumebinding.png[winweb03 - Waiting for Volume Binding,link=self, window=blank, width=100%]
+
.. `Provisioning` - ターゲットの OpenShift Node の特定、コンピュートリソースの準備、VM イメージのダウンロードを行います。
+
image::module-3-provisioning.png[winweb03 - Provisioning,link=self, window=blank, width=100%]
+
.. `Running` - 仮想マシンが利用可能な状態になります。
+
.新しい仮想マシンが実行中になったら削除してください
image::module-3-running.png[winweb03 - Running,link=self, window=blank, width=100%]

[[deleting]]
== 仮想マシンの削除

. ワークショップクラスターのリソースを確保するため、新しい仮想マシンを *削除* してください。
.. *Actions -> Delete* をクリックし、確認ダイアログで *Delete* をクリックしてリソースを解放します。
+
.仮想マシンの削除を確認
image::module-3-vm-deleting.png[winweb03 - Deleting,link=self, window=blank, width=100%]

WARNING: `winweb03` を削除しないと、このワークショップを最後まで完了できない可能性があります。
