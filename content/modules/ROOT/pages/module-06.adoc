= （オプション）ネットワーク Egress ファイアウォール

NOTE: このモジュールはオプションです。時間に余裕がある方はチャレンジしてみてください。

== はじめに

セキュリティはあらゆる組織にとって重要です。
最小権限の原則は、アプリケーションのアクセスを運用に必要なリソースのみに制限する一般的なセキュリティプラクティスです。
例えば、アプリケーションがインターネットアクセスを必要としないことが分かっている場合、そのアプリケーションのインターネットアクセスをブロックするポリシーを作成すべきです。

実際の環境では、アウトバウンドプロキシ/VLAN/ファイアウォールでこの課題を解決しますが、これらのソリューションは高コストで実装が複雑になりがちです。
ここでは、OpenShift Virtualization を使って、わずか数クリックでセキュリティレイヤーを追加できることを示します。

このモジュールでは、OpenShift に組み込まれたクラウドネイティブ機能を使って、Windows 仮想マシンからインターネットへの Egress アクセスをブロックするテストを行います。

[[access]]
== Windows 仮想マシンからのインターネットアクセス

. *VirtualMachines* をクリックし、*winweb01* をクリックしてから *Console タブ* をクリックします。
Windows 仮想マシンの管理インターフェースにすでにログインしています。
+
.`winweb01` 仮想マシンのコンソールを開く
image::module-5-winweb01-console.png[Windows virtual machine console,link=self, window=blank, width=100%]

. *`15` と入力* して *Enter* キーを押し、PowerShell を起動します。
+
.PowerShell の起動
image::module-5-powershell-01.png[Powershell Activation,link=self, window=blank, width=100%]
+
. 以下のコマンドを *コピー* し、*特殊な Paste ボタン* で仮想マシンコンソールに貼り付けます。
仮想マシンコンソールをクリックして *Enter* キーを押します。
接続が成功し、`StatusCode: 200` と表示されることを確認します。
+
[,console,subs="attributes",role=execute]
----
curl google.com -UseBasicParsing -TimeoutSec 1 | findstr StatusCode
----
+
.PowerShell cURL 成功: `StatusCode: 200`
image::module-5-powershell-curl-success.png[Powershell cURL success,link=self, window=blank, width=100%]

[[policy]]
== Egress をブロックする NetworkPolicy の実装

. 左側で *Networking -> NetworkPolicies -> Create NetworkPolicy* をクリックします。
+
.NetworkPolicy の作成を開始
image::module-5-netpol-create.png[Create NetworkPolicy,link=self, window=blank, width=100%]
+
. YAML View ラジオボタンを選択します。
+
.YAML マニフェストを使った NetworkPolicy の作成
image::module-5-netpol-complete.png[NetworkPolicy Complete,link=self, window=blank, width=100%]
+
. サンプル YAML を以下の NetworkPolicy に置き換えます。
+
[,yaml,subs="attributes",role=execute]
----
kind: NetworkPolicy
apiVersion: networking.k8s.io/v1
metadata:
 name: noegress
 namespace: windowsmesh-{user}
spec:
 podSelector:
   matchLabels:
     app: winmesh
 policyTypes:
   - Egress
----
+
. コンソールが以下のようになったら *Create をクリック* します。

[[validate]]
== Windows 仮想マシンからのインターネットアクセスがブロックされたことを確認

. PowerShell に戻り、インターネットへのネットワーク接続をテストします。
*Virtualization -> VirtualMachines -> winweb01 -> Console* をクリックします。
コンソールをクリックし、インターネットアクセスのテストを繰り返します。
*同じコマンドを再実行するには、上矢印キーを押して Enter を押します。*
+
.cURL インターネットアクセステストの失敗
image::module-5-powershell-curl-failure.png[Powershell cURL failure,link=self, window=blank, width=100%]
+
インターネットへの Egress 接続がタイムアウトで拒否されました。

== No-Egress ポリシーの削除

WARNING: ラボの終了前に、この NetworkPolicy を削除してください。VM のネットワーク接続が制限されたままになります。
